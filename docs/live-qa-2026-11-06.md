Authorization is distinct from a policy allow-list. Asset minting requires the signer to match the live issuer; unreadable issuer state refuses approval. Contract calls require a successful supported pre-sign simulation in the console; an unknown Revive call simulation refuses the wallet request. The signed dry run is still required before submission. Permissionless contract calls do not require inventing an issuer role.

Manual follow-up after automated validation: unauthorized DUCAT mint must be refused before any wallet signature popup; an authorized asset mint must still be reviewable; tiny native swaps must show the fee warning; policy edits and quote expiry must clear approval; imported native receipts must verify without connecting a wallet.
