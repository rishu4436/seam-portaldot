# Portaldot Hacker House 2026 checklist

All times IST. Source: the DoraHacks page, read Oct 11, 2026. Re-check it before each deadline.

## Dates
- [ ] **Oct 14, 5:30 PM:** kickoff. Get the V3 testnet RPC and faucet, and ask whether Revive and Nfts are live.
- [ ] **Oct 22 (our target):** real testnet transactions from the demo flow, saved to `evidence/`.
- [ ] **Oct 23 (our target):** check-in video recorded.
- [ ] **Oct 24, 5:30 PM, check-in:** progress notes, the public repo, an architecture diagram, testnet contract addresses and transaction hashes, and a live demo or a video of 3 minutes or less.
- [ ] **Oct 27:** last day to apply for office hours (held Oct 28 and 29). Optional.
- [ ] **Nov 3 (our target):** feature freeze, with the final video and pitch deck done.
- [ ] **Nov 6, 9:30 AM, final deadline and code freeze.**
- [ ] **Nov 8 to 9:** demo day.

## Rules
- [ ] The repo is public, with real commits spread across the build period. No core module lands in one drop in the last 24 hours.
- [ ] The project wasn't finished before the hackathon. Keep the Portaldot team's message allowing early coding, in case judges ask about the Oct 11 commit dates.
- [ ] Deployed on the Portaldot testnet with real on-chain activity.

## Final submission
- [ ] README with deploy steps, docs and runnable code.
- [ ] Testnet deployment info: contract addresses and transaction hashes.
- [ ] A runnable demo link, or local setup steps.
- [ ] A public demo video of 3 minutes or less, showing the real product and how it uses Portaldot.
- [ ] A pitch deck covering the problem, why Portaldot is essential, and proof it works.

## Judging, and where we earn it
| Criterion | Weight | Our evidence |
|---|---|---|
| Technical feasibility | 30% | Steady commits, 160+ automated tests, real testnet transactions with verified receipts. |
| Innovation | 30% | One Manifest compiled from live metadata, the runtime lock, approval binding, verified receipts, WASM contracts. |
| Ecosystem contribution | 20% | Open-source SDK, CLI and docs that other Portaldot apps can use directly. |
| Business potential | 20% | RuntimeGuard as a hosted service, and SEAM as the safety layer for wallets and AI agents. |
