# Three-minute recording guide

This is preparation material for the project team. It is not part of the application UI.

Use a funded V3 testnet account and record the real wallet prompts and finalized result.

| Time      | Segment                                                                                                            |
| --------- | ------------------------------------------------------------------------------------------------------------------ |
| 0:00–0:30 | Explain why a raw transaction prompt cannot establish intent or prove execution.                                   |
| 0:30–1:30 | Connect the wallet, read balances, compile an asset transfer, review policy and sign.                              |
| 1:30–2:15 | Export the receipt, inspect it against finalized chain evidence, and compare a tampered receipt with the original. |
| 2:15–3:00 | Share the original receipt, verify it on the backend, open runtime monitoring, and show the reusable SDK.          |

Keep historical evidence clearly identified. Do not describe a replay or a read-only verification as a newly signed transaction.
